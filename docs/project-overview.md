# 🏀 CourtVision — Android Basketball AI Tracker

> Android-native basketball performance tracking app using on-device AI, computer vision, and AR-assisted court mapping to deliver real-time shot analytics, biomechanical metrics, and player development insights.

---

## 📋 Project Overview

| Field | Details |
| --- | --- |
| **Platform** | Android (API 26+) |
| **Stage** | Planning / Pre-Development |
| **Version** | 1.0 |
| **Date** | March 2026 |
| **Comparable Product** | HomeCourt (iOS) |
| **Target Launch** | 12 months from kickoff |
